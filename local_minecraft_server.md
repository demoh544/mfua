# Создаем локальный маинкрафт сервер на arch linux 
### Зависимости и ядро

- java 21
- ядро fabric

Устанавливаем java21

`sudo pacman -S openjdk21`

Устанавливается jar ядро с официального сайта https://fabricmc.net/use/installer/

Либо через wget

`wget https://fabricmc.net -O fabric-installer.jar`

### Структура сервера

Создаем корневую папку для сераера, закидываем туда ядро fabric и запускаем ядро для генерации нужных файлов 

`java -jar fabric-installer.jar server -mcversion 1.21.11 -downloadMinecraft`

Далее нужно принять пользовательское соглашение в появившемся файле elua.txt

Открываем elua.txt в любом текстовом редакторе и меняем значение elua на true
Либо

`echo "eula=true" > eula.txt`

### Запуск

Далее нужно создать скрипт запуска, либо просто вводить одну и туже команду при каждом включении сервера

```
!#/bin/bash
java -Xmx4G -Xms4G -jar fabric-server-launch.jar nogui
#Простой запуск с колличеством оперативной памити в 4Gb 
```

Далее делаем скрипт запуска исполняемым 

`sudo chmod +x start.sh`

далее остается просто запустить сервер

`./start.sh`

или

`sh start.sh`

### Поключение

Подключение происходит по адресу localhost или 127.0.0.1

И по умолчанию сервер работает на порту 25565

### Редактирование настроек

Все настройки ядра лежат в файле server.properties
